# Portofolio Dafa (React + Vite + Tailwind CSS v4)

## Menjalankan
1. npm install
2. npm run dev      -> buka http://localhost:5173
3. npm run build    -> hasil di folder dist (siap deploy ke Vercel/Netlify)

## Mengganti konten
Semua teks, skill, proyek, dan link: src/data/content.js
Warna tema (bagian @theme): src/index.css
